# Fuel Ops Dashboard

Interactive dashboard เดี่ยวไฟล์เดียว (`index.html`) เชื่อมข้อมูลสดจาก Google Sheet ที่ให้มา ไม่ต้อง build ใดๆ

## วิธีนำไปใช้บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (public หรือ private ก็ได้ ถ้าจะใช้ GitHub Pages ฟรีต้องเป็น public หรือมี GitHub Pro สำหรับ private)
2. อัปโหลดไฟล์ `index.html` ไว้ที่ root ของ repo
3. ไปที่ Settings → Pages → เลือก branch (เช่น `main`) และ folder `/root` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ประมาณ `https://<username>.github.io/<repo>/`

## ข้อกำหนดของ Google Sheet

- ต้องตั้งค่าการแชร์เป็น **"ทุกคนที่มีลิงก์ – ผู้ดู (Viewer)"** ไม่เช่นนั้น dashboard จะโหลดข้อมูลไม่ได้ เพราะไฟล์นี้ดึงข้อมูลตรงจาก endpoint export ของ Google Sheets แบบไม่ใช้ login
- โครงสร้างคอลัมน์ต้องเหมือนกับไฟล์ต้นฉบับที่ให้มา คือ (เรียงตามลำดับ):
  `BU, Year-Month, รถ, ขายสด (Liter), ขายเชื่อ (Liter), ขายสด (THB), ขายเชื่อ (THB), ต้นทุนขาย (THB), กำไรขั้นต้น, จำนวนเที่ยววิ่ง, ระยะทาง (กม.), เติมน้ำมัน (Liter), น้ำมันขาดเกิน (Liter), อัตราการใช้น้ำมัน, ค่าซ่อม`
- คอลัมน์ `Year-Month` ต้องเป็นรูปแบบ `YYYY-MM` เช่น `2026-05` เพื่อให้ dashboard เทียบเดือนเดียวกันของปีก่อนได้ถูกต้อง
- ถ้าจะเปลี่ยนไปใช้ Google Sheet คนละไฟล์ ให้แก้ค่า `SHEET_ID` ที่ต้นไฟล์ `index.html` (บรรทัดแรกๆ ใน `<script>`) เป็น ID ของชีตใหม่ (ส่วนที่อยู่ระหว่าง `/d/` กับ `/edit` ใน URL)

## ฟีเจอร์หลัก

- ตัวเลือก "เดือน-ปี" และ "หน่วยธุรกิจ (BU)" ที่ด้านบน กรองข้อมูลทั้งหน้าแบบเรียลไทม์
- ทุกเดือนที่เลือกจะเทียบกับเดือนเดียวกันของปีก่อนหน้าโดยอัตโนมัติ
- ปุ่ม "รีเฟรช" ดึงข้อมูลใหม่จาก Google Sheet ทันทีโดยไม่ต้อง reload หน้า
- ปุ่ม "ธีม" สลับโหมดสว่าง/มืด
- KPI ภาพรวม: จำนวนลิตร, ยอดขาย, กำไรขั้นต้น, น้ำมันขาด-เกิน, สัดส่วนเงินสด-เงินเชื่อ (พร้อม % เปลี่ยนแปลงเทียบปีก่อน)
- กราฟรายคัน/หน่วย 9 กราฟ ครอบคลุมยอดขายลิตร, % เปลี่ยนแปลง, น้ำมันขาด-เกิน, กำไรขั้นต้น (รวมและเฉลี่ยต่อลิตร), ต้นทุนขายเฉลี่ยต่อลิตร, ค่าซ่อม, อัตราการใช้น้ำมัน, สัดส่วนเงินสด-เงินเชื่อรายคัน
- ตารางค่าซ่อมประจำเดือนแยกรายคัน

## ข้อจำกัดที่ควรทราบ

- ข้อมูลต้นทางมีเฉพาะ **ยอดค่าซ่อมรวมต่อคันต่อเดือน** ไม่มีรายการซ่อมแยกเป็นรายการย่อย (เช่น วันที่ซ่อม, รายละเอียดอะไหล่) ตารางค่าซ่อมในหน้านี้จึงเป็นยอดสรุปรายคัน หากต้องการ log ละเอียดกว่านี้ ต้องเพิ่มชีตย่อยหรือคอลัมน์ใหม่ในฐานข้อมูลต้นทาง แล้วอาจต้องปรับโค้ดส่วนตารางเพิ่มเติม
- สัดส่วน "เงินสด-เงินเชื่อ" คำนวณจาก **จำนวนลิตร** (ไม่ใช่จำนวนบาท) เพราะเป็นตัวเลขที่สะท้อนปริมาณการขายเชื้อเพลิงโดยตรง หากต้องการคำนวณจากยอดเงินบาทแทน แจ้งได้ ปรับโค้ดจุดเดียว
- "กำไรขั้นต้นเฉลี่ยรายคัน" และ "ต้นทุนขายเฉลี่ยรายคัน" คำนวณเป็น **บาทต่อลิตร** (กำไร/ต้นทุน หารด้วยลิตรขายรวม) ซึ่งเป็นนิยาม "เฉลี่ย" ที่ใช้บ่อยที่สุดสำหรับธุรกิจนี้ — ถ้าต้องการนิยามอื่น (เช่น เฉลี่ยต่อเที่ยววิ่ง) แจ้งได้เช่นกัน
